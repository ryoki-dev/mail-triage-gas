# 問い合わせメール自動仕分けツール（Google Apps Script + Claude API）

問い合わせ用アドレスに届くメールを、担当者が読む前に **AIで自動分類・要約** し、
スプレッドシートに一覧化します。緊急度の高いものは **Slack に即時通知** します。

> 個人事業主・中小企業の「問い合わせ対応の抜け漏れ」を減らすための小さな自動化ツールです。
> サンプル（合成データ）で動作確認できるデモ用リポジトリです。

---

## できること

| | |
|---|---|
| 🏷 **自動分類** | 「見積・料金」「不具合・クレーム」「一般問い合わせ」「営業」「スパム」などに振り分け（カテゴリはスプレッドシートで自由に定義） |
| ⚡ **優先度づけ** | 高 / 中 / 低。判定方針はスプレッドシートの文章で調整でき、コード変更不要 |
| 📝 **3行要約 + 推奨アクション** | 本文を読まなくても対応方針が分かる |
| 📊 **一覧化** | 1問い合わせ = スプレッドシート1行。「対応状況」列で対応漏れを管理 |
| 🔔 **Slack通知** | 指定した優先度の問い合わせをIncomingWebhookで即時通知 |
| 🔁 **自動実行** | 時間主導トリガーで15分ごと（間隔は変更可） |

出力例 → [`docs/SAMPLE_OUTPUT.md`](docs/SAMPLE_OUTPUT.md)
仕様 → [`docs/SPEC.md`](docs/SPEC.md)

## アーキテクチャ

```
                 ┌──────────────┐
  Gmail  ───────▶│ Apps Script  │───────▶ Claude API（分類・要約／構造化出力）
 （問い合わせ）   │   run()      │◀───────  { category, priority, summary, ... }
                 └──────┬───────┘
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
   スプレッドシート   Gmailラベル     Slack
   （ログ / 実行ログ） （カテゴリ別）  （優先度=高 など）
```

- Claude の呼び出しは **構造化出力（`output_config.format` / JSON Schema）** を使用し、
  応答が必ず指定のスキーマになることを保証しています。
- **業務ルールをコードに書かない** 設計です。分類カテゴリ・優先度の方針・対象メール・
  通知条件はすべてスプレッドシートの「設定」「カテゴリ」シートで管理します。

## セットアップ

### 前提

- Google アカウント
- Anthropic API キー（<https://console.anthropic.com/> で発行）
- （任意）Slack の Incoming Webhook URL

### 手順

1. **Apps Script プロジェクトを作成**
   [script.google.com](https://script.google.com/) で新規プロジェクトを作成し、
   `src/` 内の `.gs` ファイルと `appsscript.json` を貼り付ける
   （または後述の clasp でまとめて push）。

2. **APIキーを登録**
   プロジェクトの設定 → 「スクリプト プロパティ」で以下を追加:

   | プロパティ | 値 |
   |---|---|
   | `ANTHROPIC_API_KEY` | `sk-ant-...` |
   | `SLACK_WEBHOOK_URL` | （任意）`https://hooks.slack.com/services/...` |

3. **`initialSetup` を実行**
   エディタで関数 `initialSetup` を選んで実行。初回は権限承認が必要です。
   - ログ用スプレッドシートが新規作成され、そのIDが `SPREADSHEET_ID` に自動保存されます
   - 「設定」「カテゴリ」「ログ」「実行ログ」シートが既定値つきで作られます
   - 15分ごとの実行トリガーが登録されます
   - 実行ログにスプレッドシートのURLが出力されます

4. **Gmail 側の準備**
   問い合わせメールに `問い合わせ` ラベルが付くようにします
   （Gmail のフィルタで「宛先が info@… なら ラベル:問い合わせ を付ける」など）。
   ラベル名を変えたい場合は「設定」シートの検索クエリを編集してください。

5. **設定を自社向けに調整**
   作成されたスプレッドシートを開き、
   - 「カテゴリ」シート … 分類先を追加・削除
   - 「設定」シート … 優先度の判定方針、通知する優先度、1回の処理数 などを調整

6. **テスト実行**
   関数 `previewNextBatch` を実行すると、Gmail もラベルも変更せずに
   数件だけ分類して「ログ」シートに書き出します。結果を確認してください。

7. **本番稼働**
   問題なければ「設定」シートの **ドライラン** を `false` にします。
   以降、トリガーが自動で処理します。

### clasp を使う場合（任意）

```bash
npm install -g @google/clasp
clasp login
cp .clasp.json.example .clasp.json   # scriptId を記入
clasp push
```

## 設定項目（「設定」シート）

| キー | 既定値 | 説明 |
|---|---|---|
| 対象Gmail検索クエリ | `label:問い合わせ -label:仕分け済み newer_than:7d` | 処理対象の絞り込み |
| 1回の最大処理数 | `20` | API課金・実行時間の上限 |
| 本文の最大文字数 | `4000` | AIに渡す本文の切り詰め長 |
| 通知する優先度 | `高` | Slack通知対象（`高,中` のように複数可） |
| 仕分け済みラベル名 | `仕分け済み` | 完了スレッドに付けるラベル |
| 優先度の判定方針 | （文章） | AIに渡す優先度ガイドライン |
| ドライラン | `false` | true の間はGmail変更・Slack通知なし |
| Claudeモデル | `claude-opus-5` | 下記「コスト」参照 |

## コストの目安

問い合わせ1通あたり、入力〜800トークン・出力〜200トークン程度。
（1 USD = 150 円換算、2026年6月時点の料金）

| モデル | 1通あたり | 月300通 | 特徴 |
|---|---|---|---|
| `claude-opus-5`（既定） | 約 1.3 円 | 約 400 円 | 判断の精度重視 |
| `claude-sonnet-5` | 約 0.5 円 | 約 160 円 | バランス型 |
| `claude-haiku-4-5` | 約 0.25 円 | 約 75 円 | 大量処理・コスト重視 |

分類タスクは比較的軽いため、量が多い場合は「設定」シートの「Claudeモデル」を
`claude-haiku-4-5` または `claude-sonnet-5` に変更するとコストを大きく下げられます。
まず `claude-opus-5` で精度を確認し、必要に応じて下げるのがおすすめです。

## テスト

Apps Script エディタで `runAllTests`（`test/Tests.gs`）を実行すると、
ネットワークに触れない純粋関数（差出人パース、設定パース、構造化出力の取り出しなど）の
単体テストが走り、ログに結果が出ます。

## 実装メモ

- **言語 / 実行基盤**: Google Apps Script（V8 ランタイム）
- **Claude API**: `POST /v1/messages` を `UrlFetchApp` で呼び出し（GASに公式SDKが無いため生HTTP）。
  構造化出力・`effort: "low"`・429/5xx の指数バックオフ再試行を実装
- **必要スコープ**: `gmail.modify` / `spreadsheets` / `script.external_request` / `script.scriptapp`
- **冪等性**: 「仕分け済み」ラベル + ログ済みメッセージIDの二重チェック
- **エラー分離**: 1通の失敗は `対応状況=ERROR` で記録して継続、次回リトライ
